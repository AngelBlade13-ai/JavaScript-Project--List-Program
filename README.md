# JavaScript Product List Program

A small JavaScript list-building exercise. Users type a product name, submit it, and the script stores the product in an array before rendering the current product list on the page.

## Features

- Product input form
- Empty-input validation
- Product objects stored in an array
- Dynamic output generated with JavaScript
- Console logging for debugging array state

## How To Run

Open `index.html` in a browser.

## Files

```text
index.html
style.css
script.js
```

## What I Practiced

- Reading input values
- Validating form input
- Creating objects
- Pushing objects into arrays
- Looping through arrays to render output
